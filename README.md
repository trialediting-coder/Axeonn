# Axeon Studio

Marketing site for Axeon Studio (axeonstudio.co) — a Next.js 15 App Router application.

## Development

```bash
npm install
npm run dev
```

## Build & Verify

```bash
npm run build
npm run lint
npx tsx scripts/verify-build.mjs
# ...and the other verify-*.mjs scripts in scripts/
```

Deployed on Vercel.
