# Meta Inbox and Reels (Slice 6 of the PROOF Lead System) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Facebook Messenger and Instagram DMs land in the AxeonPROOF leads inbox as contacts with a timeline and a working reply box (within Meta's 24-hour window), and AxeonGROWTH clients get reels scheduled and posted to Instagram and Facebook with reach shown in PROOF.

**Architecture:** One Meta app (Axeon's), connected per client through Facebook Login from the portal or the admin card. Each page's long-lived token is sealed with `lib/secretBox.ts` (AES-256-GCM) in `meta_pages`. Meta posts every DM to one signed webhook, `/api/meta/webhook`, which verifies `X-Hub-Signature-256` on the raw body, answers 200 at once, and records the messages in `after()`: `meta_messages` (deduped on `mid`), then a contact keyed by PSID / IGSID and its timeline event through slice 4's `lib/contacts.ts` (`upsertContactByExternalId` and `addContactEvent`, added there in Task 4 because slice 4's `upsertContactEvent` only resolves a phone or an email), then slice 4's `notifyLeadActivity` (`lib/leadNotify.ts`: push first, owner text and email as the fallback). Inbox replies go through the Send API when the contact's latest inbound touch was a DM and the window is open. Reels: browser → Vercel Blob → `social_posts` → an hourly cron runs Instagram's container flow and Facebook's `/videos` call, and refreshes Instagram reach daily.

**Tech Stack:** Next.js 15 App Router route handlers (`runtime = 'nodejs'`, `after()` from `next/server`), `@vercel/postgres` via `lib/db.ts`, Meta Graph API `v21.0` over `fetch` (no SDK; every function takes an injectable fetch), `node:crypto` (AES-256-GCM, HMAC-SHA256), `@vercel/blob` 2.8.0 client uploads, `tsx --test` + `node:assert/strict`, Tailwind + `components/admin/ui.ts`.

**Spec:** `docs/superpowers/specs/2026-10-12-proof-lead-system-design.md` ("Architecture (all slices)", "Cross-slice decisions", "Slice 4 design", "Slice 4 additions", "Slice 6 design", "Execution order").

## Global Constraints

- **503 until configured.** Every Meta route (`/api/meta/*`, the admin Meta and Social APIs, the upload route, the social cron) returns 503 `{ error: 'Meta is not configured' }` unless `META_APP_ID`, `META_APP_SECRET`, `META_VERIFY_TOKEN` and `SECRETS_KEY` (32 bytes, base64) are all set. One helper decides it: `metaUnavailable()` in `lib/meta.ts`. The cron checks `CRON_SECRET` first (401), then this.
- **Page tokens are stored only through `lib/secretBox.ts`**: AES-256-GCM, a random 12-byte IV per seal, key from `SECRETS_KEY` (base64), output `v1.<iv>.<tag>.<ciphertext>` in base64url. Tokens are opened only inside `pageForId` (lib/metaPages.ts). No API response, page prop, log line or error message ever carries a token: API code maps rows with `toPublicPage`, and every Graph error and every logged error passes through `secretRedact`.
- **Signature first.** The webhook verifies `X-Hub-Signature-256` = `sha256=` + HMAC-SHA256(app secret, raw body) with `timingSafeEqual` on the raw bytes, before any `JSON.parse`. A bad or missing signature is a 403 and nothing is parsed.
- **Always a fast 200.** A signed webhook POST answers 200 within milliseconds; all database and Graph work runs in `after()`. Meta retries slow or failed deliveries and eventually disables the subscription. A signed body that is not JSON is still a 200 with no work.
- **Dedupe on `message.mid`.** `meta_messages.mid` is `UNIQUE`; the insert is `ON CONFLICT (mid) DO NOTHING RETURNING id`, and nothing else (contact, event, alert) happens when no row comes back.
- **The 24-hour window is enforced before any Send API call** (`replyDecision` in `lib/metaShared.ts`, with a one-minute safety margin). Meta's own window error (code 10 / subcode 2018278) maps to the same 409 copy.
- **Reels are AxeonGROWTH only**: `assertGrowth` in the API, the upload route refuses other tiers, the cron joins `onboardings.tier = 'axeongrowth'`, the admin card renders nothing for other tiers, and PROOF loads reels only for GROWTH.
- **Connections are bound to one client.** OAuth `state` is HMAC-signed (15-minute expiry) and carries the onboarding token; a nonce cookie ties the callback to the browser that pressed Connect; the portal start requires a verified device and the admin start requires an admin session; a page already connected to another client is refused, never moved.
- Every new table goes in both `lib/db.ts` `ensureSchema()` and `scripts/init-db.mjs`, `IF NOT EXISTS` only; a rewritten CHECK uses the existing pattern: `DROP CONSTRAINT IF EXISTS`, then `ADD CONSTRAINT` inside a `try` that ignores Postgres `42710` (duplicate_object), exactly as `phone_messages_kind_check` does in both files.
- Reuse, do not copy: `DbId`, `DbTime`, `iso`, `errText` from `lib/dbRows.ts`; contacts and timeline events are written only through `lib/contacts.ts` (slice 4; its `insertEvent` and `advanceStage` stay private, so the two Meta functions live in that module); owner alerts only through slice 4's `notifyLeadActivity`; the inbox reply only through slice 4's `POST /api/proof/inbox/[contactId]/reply`. Quiet hours (8 pm to 8 am, `lib/leadShared.ts`) govern automated texts; a Meta reply is typed by the client and is not a text, so it is not held (Task 7).
- Client-safe modules (`lib/metaShared.ts`, `lib/socialShared.ts`, `data/onboardingItems.ts`) import nothing from `node:*` or `@/lib/db`.
- Tests run with `tsx --test` and need no database or network: fetch is always injected; SQL functions are not unit-tested, pure helpers are.
- Client-facing copy is plain language ("Connect your Facebook page", "Facebook only lets you reply within 24 hours of their last message"), never "OAuth", "webhook" or "token".

## Review Focus

1. **Signature on raw bytes, before parsing.** A POST with no, a wrong, or a truncated `X-Hub-Signature-256` must be a 403 and must never reach `JSON.parse`; the HMAC must be over the exact bytes received. Pinned in Task 3 (`verifySignature` against a pinned HMAC, including a one-byte change) and Task 6 (`readMetaWebhook` 403 cases, "not json and unsigned is still 403").
2. **Redelivery never doubles a lead.** Meta retries the same `mid`; the second delivery must stop at the `meta_messages` insert with no contact upsert, no event and no alert, and the 200 must not wait on any of it. Pinned in Task 2 (duplicate `mid` inside one payload kept once) and Task 6 (`recordOne` returns `'duplicate'` before touching contacts; the route returns before `after()` work runs).
3. **A token never leaves the server.** Sealed at rest, opened only in `pageForId`, absent from every API shape, and masked in every error and log, including network errors that echo the URL. Pinned in Task 1 (sealed form never contains the token; wrong key and tampering refused), Task 3 (Graph 190 error and a fetch failure carrying `access_token` / `client_secret` / `code` come out masked), and Task 4 (`toPublicPage` keys).
4. **No Send API call outside the window.** A reply to a DM older than 23 h 59 m must be refused with the 409 copy before `sendMessage` runs, and a newer text or call routes the reply to SMS instead. Pinned in Task 2 (`withinMessagingWindow` boundary at exactly 24 h minus 60 s; `replyDecision` cases) and Task 7 (`metaReplyFor` returns before `pageForId` / `sendMessage` on `blocked`).
5. **Nobody can attach their page to someone else's client.** Forged or expired `state`, a callback without the matching nonce cookie, an unverified portal device, and a page already owned by another onboarding must all fail. Pinned in Task 3 (`signState` / `verifyState`: tamper, wrong secret, expiry) and Task 5 (callback nonce check; `savePage`'s `WHERE meta_pages.onboarding_id = EXCLUDED.onboarding_id`).

```ts
// lib/secretBox.ts
// The one place a third-party secret is stored per client (spec, "Cross-slice
// decisions": one secrets helper). AES-256-GCM with SECRETS_KEY (32 bytes,
// base64, generated once by the owner), a fresh random 12-byte IV per seal, and
// the GCM tag checked on open so a tampered row fails loudly instead of
// decrypting to garbage. Output: v1.<iv>.<tag>.<ciphertext>, each base64url.
// Errors never carry the plaintext or the key. Server-only.
import { createCipheriv, createDecipheriv, randomBytes } from 'node:crypto';

const VERSION = 'v1';
const IV_BYTES = 12;
const TAG_BYTES = 16;

function keyFrom(raw: string | undefined): Buffer | null {
  if (!raw) return null;
  const key = Buffer.from(raw.trim(), 'base64');
  return key.length === 32 ? key : null;
}

function requireKey(raw: string | undefined): Buffer {
  const key = keyFrom(raw);
  if (!key) throw new Error('SECRETS_KEY must be set to 32 random bytes, base64 (openssl rand -base64 32)');
  return key;
}

export function isSecretsConfigured(): boolean {
  return keyFrom(process.env.SECRETS_KEY) !== null;
}

/** Encrypts a secret for storage. `rawKey` exists for tests; production reads SECRETS_KEY. */
export function seal(plain: string, rawKey: string | undefined = process.env.SECRETS_KEY): string {
  const key = requireKey(rawKey);
  const iv = randomBytes(IV_BYTES);
  const cipher = createCipheriv('aes-256-gcm', key, iv);
  const ciphertext = Buffer.concat([cipher.update(plain, 'utf8'), cipher.final()]);
  const tag = cipher.getAuthTag();
  return [VERSION, iv.toString('base64url'), tag.toString('base64url'), ciphertext.toString('base64url')].join('.');
}

/** Decrypts what seal() produced. Throws on a wrong key, a tampered value or a malformed string. */
export function open(sealed: string, rawKey: string | undefined = process.env.SECRETS_KEY): string {
  const key = requireKey(rawKey);
  const parts = typeof sealed === 'string' ? sealed.split('.') : [];
  if (parts.length !== 4 || parts[0] !== VERSION) throw new Error('Not a sealed secret');
  const iv = Buffer.from(parts[1], 'base64url');
  const tag = Buffer.from(parts[2], 'base64url');
  const ciphertext = Buffer.from(parts[3], 'base64url');
  if (iv.length !== IV_BYTES || tag.length !== TAG_BYTES) throw new Error('Not a sealed secret');
  try {
    const decipher = createDecipheriv('aes-256-gcm', key, iv);
    decipher.setAuthTag(tag);
    return Buffer.concat([decipher.update(ciphertext), decipher.final()]).toString('utf8');
  } catch {
    // GCM's own message ("Unsupported state or unable to authenticate data") is fine, but say it plainly.
    throw new Error('Could not open the sealed secret (wrong SECRETS_KEY or the value was changed)');
  }
}
```

```ts
const str = (v: unknown): string => (typeof v === 'string' ? v : typeof v === 'number' ? String(v) : '');
const obj = (v: unknown): Record<string, unknown> | null => (v && typeof v === 'object' && !Array.isArray(v) ? (v as Record<string, unknown>) : null);
const arr = (v: unknown): unknown[] => (Array.isArray(v) ? v : []);

/**
 * Turns a verified webhook body into the DMs worth recording. Messenger posts
 * object "page", Instagram posts object "instagram"; both carry entry[].messaging[]
 * with sender.id, recipient.id, timestamp and message { mid, text, attachments }.
 * Echoes (our own sends, or the owner replying in Meta Business Suite), reads,
 * deliveries, reactions and postbacks without a message are skipped. Duplicate
 * mids inside one delivery are kept once.
 */
export function parseWebhookBody(json: unknown): MetaInboundMessage[] {
  const body = obj(json);
  if (!body) return [];
  const object = body.object;
  if (object !== 'page' && object !== 'instagram') return [];
  const channel: MetaChannel = object === 'instagram' ? 'instagram' : 'messenger';
  const out: MetaInboundMessage[] = [];
  const seen = new Set<string>();
  for (const rawEntry of arr(body.entry)) {
    const entry = obj(rawEntry);
    if (!entry) continue;
    for (const rawEvent of arr(entry.messaging)) {
      const event = obj(rawEvent);
      const message = obj(event?.message);
      if (!event || !message) continue;
      if (message.is_echo === true || message.is_deleted === true) continue;
      const mid = str(message.mid);
      const senderId = str(obj(event.sender)?.id);
      const pageOrIgId = str(obj(event.recipient)?.id) || str(entry.id);
      if (!mid || !senderId || !pageOrIgId || seen.has(mid)) continue;
      seen.add(mid);
      const attachments: MetaAttachment[] = arr(message.attachments)
        .map(obj)
        .filter((a): a is Record<string, unknown> => a !== null)
        .map((a) => ({ type: str(a.type) || 'file', url: str(obj(a.payload)?.url) || null }));
      const timestamp = Number(event.timestamp ?? entry.time ?? 0);
      out.push({
        channel,
        pageOrIgId,
        senderId,
        mid,
        text: str(message.text).slice(0, 4000),
        attachments,
        timestamp: Number.isFinite(timestamp) && timestamp > 0 ? timestamp : 0,
      });
    }
  }
  return out;
}

/** True while Meta still allows a standard reply: within 24 hours (less a minute) of the person's last message. */
export function withinMessagingWindow(lastInboundAt: string | number | Date | null | undefined, now: number | Date = Date.now()): boolean {
  if (lastInboundAt == null || lastInboundAt === '') return false;
  const last = time(lastInboundAt);
  if (!Number.isFinite(last)) return false;
  return time(now) - last < MESSAGING_WINDOW_MS - WINDOW_SAFETY_MS;
}

function sameString(a: string, b: string): boolean {
  if (a.length !== b.length) return false;
  let diff = 0;
  for (let i = 0; i < a.length; i++) diff |= a.charCodeAt(i) ^ b.charCodeAt(i);
  return diff === 0;
}

/** Meta's subscription handshake: answer hub.challenge only for mode "subscribe" and our verify token. */
export function verifyChallenge(query: URLSearchParams, verifyToken: string): string | null {
  if (!verifyToken) return null;
  if (query.get('hub.mode') !== 'subscribe') return null;
  const given = query.get('hub.verify_token') ?? '';
  const challenge = query.get('hub.challenge');
  if (!challenge || !sameString(given, verifyToken)) return null;
  return challenge;
}

export type ReplyDecision =
  | { route: 'sms' }
  | { route: 'meta'; channel: MetaChannel }
  | { route: 'blocked'; channel: MetaChannel; canText: boolean; message: string };

const PLATFORM_NAME: Record<MetaChannel, string> = { messenger: 'Facebook', instagram: 'Instagram' };

/**
 * Which way the inbox reply box sends. Meta only when the contact's most recent
 * inbound touch was a Messenger or Instagram message; the 24-hour window is
 * checked here, before any Send API call. `via: 'sms'` is the "Text them
 * instead" button and always goes to the SMS path.
 */
export function replyDecision(input: {
  lastMeta: { channel: MetaChannel; at: string } | null;
  lastOtherInboundAt: string | null;
  hasPhone: boolean;
  now: number;
  via?: 'sms' | null;
}): ReplyDecision {
  if (input.via === 'sms' || !input.lastMeta) return { route: 'sms' };
  const metaAt = time(input.lastMeta.at);
  if (input.lastOtherInboundAt && time(input.lastOtherInboundAt) > metaAt) return { route: 'sms' };
  const channel = input.lastMeta.channel;
  if (withinMessagingWindow(metaAt, input.now)) return { route: 'meta', channel };
  const name = PLATFORM_NAME[channel];
  return {
    route: 'blocked',
    channel,
    canText: input.hasPhone,
    message: input.hasPhone
      ? `${name} only lets you reply within 24 hours of their last message. Text them instead?`
      : `${name} only lets you reply within 24 hours of their last message. If they write again, you can answer here.`,
  };
}

}
```

- **Scopes.** The spec names `pages_messaging`, `instagram_manage_messages`, `instagram_content_publish`; Meta also requires `pages_show_list` (list pages), `pages_manage_metadata` (subscribe a page to the webhook), `pages_read_engagement` (read the linked Instagram account), `pages_manage_posts` (page video) and `instagram_manage_insights` (reel reach). - **Facebook reels endpoint.** v1 uses `POST /{page-id}/videos` with `file_url` and `description`: one call from the Blob URL. `/{page-id}/video_reels` needs a three-step resumable upload session (start, upload to `rupload.facebook.com`, finish) for no gain in v1; Facebook shows short vertical videos as reels either way.

```ts
  if (out instanceof Promise) return out.finally(restore);
  restore();
}
```

```ts
// lib/meta.ts
// The slice of Meta's Graph API Axeon uses, over fetch (no SDK): Facebook Login
// for a client's page, the Messenger/Instagram webhook signature, the Send API,
// and Instagram reels publishing. Every call takes an optional fetch so tests
// never touch the network. Tokens travel only in the query string or body Meta
// documents, every request carries appsecret_proof, and every error is passed
// through secretRedact so no token reaches a log or a response. Server-only.
import { createHmac, randomBytes, timingSafeEqual } from 'node:crypto';
import { secretRedact, type MetaChannel } from '@/lib/metaShared';
import { isSecretsConfigured } from '@/lib/secretBox';
import { APP_ORIGIN } from '@/lib/hostRouting';

export const GRAPH_VERSION = 'v21.0';
const GRAPH = `https://graph.facebook.com/${GRAPH_VERSION}`;
const DIALOG = `https://www.facebook.com/${GRAPH_VERSION}/dialog/oauth`;

/**
 * The spec's three scopes plus what Meta requires around them:
 * pages_show_list (list pages), pages_manage_metadata (subscribe a page to the
 * webhook), pages_read_engagement (read the linked Instagram account),
 * pages_manage_posts (page video), instagram_manage_insights (reel reach).
 */
export const META_SCOPES = [
  'pages_show_list',
  'pages_manage_metadata',
  'pages_read_engagement',
  'pages_messaging',
  'pages_manage_posts',
  'instagram_basic',
  'instagram_manage_messages',
  'instagram_content_publish',
  'instagram_manage_insights',
] as const;

export type FetchLike = (input: string, init?: RequestInit) => Promise<Response>;

const appId = () => process.env.META_APP_ID ?? '';
const appSecret = () => process.env.META_APP_SECRET ?? '';
export const metaVerifyToken = () => process.env.META_VERIFY_TOKEN ?? '';

/** All four must be set: the app, its secret, the webhook verify token, and the key that seals page tokens. */
export function isMetaConfigured(): boolean {
  return Boolean(appId() && appSecret() && metaVerifyToken() && isSecretsConfigured());
}

/** Every Meta route starts with this: null when configured, otherwise the 503 to return. */
export function metaUnavailable(): Response | null {
  return isMetaConfigured() ? null : Response.json({ error: 'Meta is not configured' }, { status: 503 });
}

/**
 * Must match a "Valid OAuth Redirect URI" in the Meta app, byte for byte. On the
 * app host (APP_URL, e.g. https://app.axeonstudio.co) because that is where the
 * portal and admin live, so the nonce cookie set by /api/meta/connect comes back.
 */
export function metaRedirectUri(): string {
  return `${APP_ORIGIN}/api/meta/callback`;
}

export class MetaApiError extends Error {
  constructor(
    message: string,
    readonly status: number,
    readonly code: number | null,
    readonly subcode: number | null
  ) {
    super(message);
    this.name = 'MetaApiError';
  }
  /** Code 190: the token expired or the person removed the app. The page must be reconnected. */
  get tokenInvalid(): boolean {
    return this.code === 190;
  }
  /** Code 10 / subcode 2018278 (and 2534022 on Instagram): the 24-hour window has closed. */
  get outsideWindow(): boolean {
    return this.code === 10 || this.subcode === 2018278 || this.subcode === 2534022;
  }
}

/** HMAC-SHA256 of the access token with the app secret, hex. Meta's "appsecret_proof". */
export function appSecretProof(accessToken: string, secret: string = appSecret()): string {
  return createHmac('sha256', secret).update(accessToken).digest('hex');
}

/**
 * Meta signs every webhook POST: X-Hub-Signature-256 = "sha256=" + hex HMAC-SHA256
 * of the raw request body with the app secret. Checked on the raw bytes, before parsing.
 */
export function verifySignature(rawBody: Buffer | string, header: string | null, secret: string): boolean {
  if (!header || !secret || !header.startsWith('sha256=')) return false;
  const given = Buffer.from(header.slice('sha256='.length), 'hex');
  const expected = createHmac('sha256', secret).update(rawBody).digest();
  return given.length === expected.length && timingSafeEqual(given, expected);
}

export interface ConnectState {
  /** The onboarding token the connection is for. */
  token: string;
  /** Random, also set as a cookie on the browser that started the flow. */
  nonce: string;
  /** Where to land afterwards. */
  from: 'portal' | 'admin';
}

export const STATE_TTL_MS = 15 * 60 * 1000;
const stateKey = (secret: string) => createHmac('sha256', secret).update('axeon-meta-state').digest();

export function newNonce(): string {
  return randomBytes(16).toString('base64url');
}

/** OAuth `state`: base64url JSON { t, n, f, e } + "." + HMAC. Self-contained; nothing stored. */
export function signState(s: ConnectState, secret: string = appSecret(), now: number = Date.now()): string {
  const payload = Buffer.from(JSON.stringify({ t: s.token, n: s.nonce, f: s.from, e: now + STATE_TTL_MS })).toString('base64url');
  const sig = createHmac('sha256', stateKey(secret)).update(payload).digest('base64url');
  return `${payload}.${sig}`;
}

export function verifyState(state: string | null, secret: string = appSecret(), now: number = Date.now()): ConnectState | null {
  if (!state || !secret) return null;
  const [payload, sig, extra] = state.split('.');
  if (!payload || !sig || extra !== undefined) return null;
  const expected = Buffer.from(createHmac('sha256', stateKey(secret)).update(payload).digest('base64url'));
  const given = Buffer.from(sig);
  if (given.length !== expected.length || !timingSafeEqual(given, expected)) return null;
  try {
    const p = JSON.parse(Buffer.from(payload, 'base64url').toString('utf8')) as { t?: unknown; n?: unknown; f?: unknown; e?: unknown };
    if (typeof p.t !== 'string' || typeof p.n !== 'string' || typeof p.e !== 'number' || p.e < now) return null;
    return { token: p.t, nonce: p.n, from: p.f === 'admin' ? 'admin' : 'portal' };
  } catch {
    return null;
  }
}

/**
 * Facebook Login dialog: https://www.facebook.com/v21.0/dialog/oauth?client_id&redirect_uri&state&scope.
 * A Business-type app using "Facebook Login for Business" asks for a saved
 * configuration instead of a scope list: set META_LOGIN_CONFIG_ID and the
 * dialog gets config_id (the configuration lists the same permissions).
 */
export function oauthUrl(state: string): string {
  const q = new URLSearchParams({ client_id: appId(), redirect_uri: metaRedirectUri(), state, response_type: 'code' });
  const configId = process.env.META_LOGIN_CONFIG_ID;
  if (configId) q.set('config_id', configId);
  else q.set('scope', META_SCOPES.join(','));
  return `${DIALOG}?${q}`;
}

type GraphInit = {
  method?: 'GET' | 'POST' | 'DELETE';
  query?: Record<string, string>;
  json?: unknown;
  /** Adds access_token and appsecret_proof to the query string. */
  token?: string;
};

/** One Graph API request. Errors come back as MetaApiError with every secret masked. */
export async function graph<T>(path: string, init: GraphInit = {}, f: FetchLike = fetch): Promise<T> {
  const query = new URLSearchParams(init.query ?? {});
  if (init.token) {
    query.set('access_token', init.token);
    query.set('appsecret_proof', appSecretProof(init.token));
  }
  const qs = query.toString();
  const url = `${GRAPH}${path}${qs ? `?${qs}` : ''}`;
  let res: Response;
  try {
    res = await f(url, {
      method: init.method ?? 'GET',
      headers: init.json !== undefined ? { 'content-type': 'application/json' } : undefined,
      body: init.json !== undefined ? JSON.stringify(init.json) : undefined,
      cache: 'no-store',
    });
  } catch (err) {
    throw new MetaApiError(secretRedact(`Meta request failed: ${err instanceof Error ? err.message : String(err)} (${path})`), 0, null, null);
  }
  const body = (await res.json().catch(() => null)) as (Record<string, unknown> & { error?: { message?: string; code?: number; error_subcode?: number } }) | null;
  if (!res.ok || body?.error) {
    const e = body?.error ?? {};
    const code = typeof e.code === 'number' ? e.code : null;
    const sub = typeof e.error_subcode === 'number' ? e.error_subcode : null;
    const label = code !== null ? ` (${code}${sub !== null ? `/${sub}` : ''})` : '';
    throw new MetaApiError(secretRedact(`Meta ${res.status}${label}: ${e.message ?? 'request failed'} (${path})`), res.status, code, sub);
  }
  if (body === null) throw new MetaApiError(`Meta ${res.status}: bad JSON (${path})`, res.status, null, null);
  return body as T;
}

/**
 * Meta's deauthorize and data-deletion callbacks POST a form field
 * signed_request = base64url(HMAC-SHA256(payload, app secret)) + "." + base64url(JSON payload).
 */
export function parseSignedRequest(signed: string | null, secret: string = appSecret()): { userId: string } | null {
  if (!signed || !secret) return null;
  const [sig, payload, extra] = signed.split('.');
  if (!sig || !payload || extra !== undefined) return null;
  const given = Buffer.from(sig, 'base64url');
  const expected = createHmac('sha256', secret).update(payload).digest();
  if (given.length !== expected.length || !timingSafeEqual(given, expected)) return null;
  try {
    const data = JSON.parse(Buffer.from(payload, 'base64url').toString('utf8')) as { algorithm?: string; user_id?: unknown };
    if (data.algorithm?.toUpperCase() !== 'HMAC-SHA256' || typeof data.user_id !== 'string' || !data.user_id) return null;
    return { userId: data.user_id };
  } catch {
    return null;
  }
}
```

```ts
import { TIER_RANK } from '@/data/onboardingItems';
import { requireAdmin } from '@/lib/adminAuth';
import { metaUnavailable, newNonce, oauthUrl, signState } from '@/lib/meta';
import { META_NONCE_COOKIE } from '@/lib/metaShared';
import { welcomeUrl } from '@/lib/onboarding';
import { isDeviceVerified, loadOnboarding, notFound } from '@/lib/welcomeApi';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

export async function GET(req: Request) {
  const unavailable = metaUnavailable();
  if (unavailable) return unavailable;
  const url = new URL(req.url);
  const onboarding = await loadOnboarding(url.searchParams.get('token') ?? '');

  const res = NextResponse.redirect(oauthUrl(signState({ token: onboarding.token, nonce, from })), 303);
  res.cookies.set({
    name: META_NONCE_COOKIE,
    value: nonce,
    httpOnly: true,
    sameSite: 'lax',
    secure: process.env.NODE_ENV === 'production',
    path: '/api/meta',
```

```ts
// app/api/meta/callback/route.ts
// Facebook Login comes back here with ?code&state (or ?error). We check the
// signed state and the nonce cookie, trade the code for a long-lived user token,
// list the pages the person granted in Meta's dialog, and for each page: find
// the linked Instagram account, seal and store the page token, and subscribe the
// page to our webhook. Then the portal item is marked done and the person lands
// back where they started with ?meta=<result>. No token is ever logged.
import { NextResponse, after } from 'next/server';
import { cookies } from 'next/headers';
import { exchangeCode, igAccountFor, listPages, longLivedToken, metaUnavailable, metaUserId, subscribePage, verifyState } from '@/lib/meta';
import { errText } from '@/lib/dbRows';
import { META_CONNECT_ITEM, META_NONCE_COOKIE, secretRedact, type ConnectResult } from '@/lib/metaShared';
import { savePage } from '@/lib/metaPages';
import { markConnectedItem, welcomeUrl } from '@/lib/onboarding';
import { afterOnboardingChange } from '@/lib/onboardingSync';
import { APP_ORIGIN } from '@/lib/hostRouting';
import { loadOnboarding } from '@/lib/welcomeApi';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

const redactedErr = (err: unknown) => secretRedact(errText(err));

export async function GET(req: Request) {
  const unavailable = metaUnavailable();
  if (unavailable) return unavailable;
  const url = new URL(req.url);
  const state = verifyState(url.searchParams.get('state'));
  if (!state) return new Response('This connection link expired. Go back to your setup page and press Connect again.', { status: 400 });
  const onboarding = await loadOnboarding(state.token);
  if (!onboarding || onboarding.status === 'closed') return new Response('Not found', { status: 404 });

  const back = (result: ConnectResult) => {
    const target = state.from === 'admin' ? `${APP_ORIGIN}/admin/onboarding/${onboarding.token}` : welcomeUrl(onboarding.token);
    const res = NextResponse.redirect(`${target}?meta=${result}`, 303);
    res.cookies.set({ name: META_NONCE_COOKIE, value: '', path: '/api/meta', maxAge: 0 });
    return res;
  };

  const jar = await cookies();
  if (jar.get(META_NONCE_COOKIE)?.value !== state.nonce) return back('error');
  if (url.searchParams.get('error')) return back('cancelled');
  const code = url.searchParams.get('code');
  if (!code) return back('error');

  try {
    const userToken = await longLivedToken(await exchangeCode(code));
    const fbUserId = await metaUserId(userToken);
    const pages = await listPages(userToken);
    if (!pages.length) return back('no-pages');
    let saved = 0;
    for (const page of pages) {
      try {
        const ig = await igAccountFor(page.id, page.accessToken).catch(() => null);
        await savePage({ onboardingId: onboarding.id, pageId: page.id, pageName: page.name, igUserId: ig?.id ?? null, igUsername: ig?.username ?? null, fbUserId, pageToken: page.accessToken });
        await subscribePage(page.id, page.accessToken);
        saved += 1;
      } catch (err) {
        console.error('[meta:callback] page', page.id, redactedErr(err));
      }
    }
    if (!saved) return back('error');
    await markConnectedItem(onboarding, META_CONNECT_ITEM);
    after(() => afterOnboardingChange(onboarding.token));
    return back('connected');
  } catch (err) {
    console.error('[meta:callback]', redactedErr(err));
    return back('error');
  }
}
```

```ts
// lib/metaWebhook.ts
// What /api/meta/webhook does before anything else: answer Meta's GET
// verification handshake, and for a POST read the raw bytes, prove they came
// from Meta (X-Hub-Signature-256 over the raw body), and only then parse.
// Returns plain Responses so it is testable without Next.
import { parseWebhookBody, secretRedact, verifyChallenge, type MetaInboundMessage } from '@/lib/metaShared';
import { metaUnavailable, metaVerifyToken, verifySignature } from '@/lib/meta';

/** Meta batches up to ~1,000 events per POST; 1 MB is far above a real delivery. */
export const META_MAX_BODY = 1024 * 1024;

export type MetaRead = { ok: true; events: MetaInboundMessage[] } | { ok: false; response: Response };

/** GET: echo hub.challenge when hub.mode=subscribe and hub.verify_token matches META_VERIFY_TOKEN. */
export function answerVerification(req: Request): Response {
  const unavailable = metaUnavailable();
  if (unavailable) return unavailable;
  const challenge = verifyChallenge(new URL(req.url).searchParams, metaVerifyToken());
  if (challenge === null) return new Response('Forbidden', { status: 403 });
  return new Response(challenge, { status: 200, headers: { 'content-type': 'text/plain' } });
}

/** POST: 503 unconfigured, 413 oversize, 403 bad signature; otherwise the parsed DMs (possibly none). */
export async function readMetaWebhook(req: Request): Promise<MetaRead> {
  const unavailable = metaUnavailable();
  if (unavailable) return { ok: false, response: unavailable };
  const declared = Number(req.headers.get('content-length'));
  if (Number.isFinite(declared) && declared > META_MAX_BODY) return { ok: false, response: new Response(null, { status: 413 }) };
  const raw = Buffer.from(await req.arrayBuffer());
  if (raw.length > META_MAX_BODY) return { ok: false, response: new Response(null, { status: 413 }) };
  if (!verifySignature(raw, req.headers.get('x-hub-signature-256'), process.env.META_APP_SECRET ?? '')) {
    return { ok: false, response: new Response(null, { status: 403 }) };
  }
  try {
    return { ok: true, events: parseWebhookBody(JSON.parse(raw.toString('utf8'))) };
  } catch (err) {
    // Signed by Meta but not JSON: acknowledge so Meta does not retry it forever.
    console.error('[meta:webhook] unreadable body', secretRedact(err instanceof Error ? err.message : String(err)));
    return { ok: true, events: [] };
  }
}
```

```ts
export async function processInbound(events: MetaInboundMessage[], now: Date = new Date()): Promise<Record<RecordResult | 'failed', number>> {
  const tally: Record<RecordResult | 'failed', number> = { recorded: 0, duplicate: 0, unknown_page: 0, failed: 0 };
  for (const e of events) {
    try {
      tally[await recordOne(e, now)] += 1;
    } catch (err) {
      tally.failed += 1;
      console.error('[meta:inbound]', e.channel, redactedErr(err));
    }
  }
  if (tally.unknown_page) console.error('[meta:inbound] messages for a page no client has connected', tally.unknown_page);
  return tally;
}
```

```ts
  | { ok: true; channel: MetaChannel }
  | { ok: false; status: number; error: string; canText: boolean; channel: MetaChannel | null };

/**
 * Called first by POST /api/proof/inbox/[contactId]/reply. Null means "not a
 * Meta thread, carry on with slice 4's SMS path". Otherwise the reply was sent
 * through Meta (ok) or refused with the status and sentence the reply box shows.
 * Every query is scoped by the onboarding id, so another client's contact is a
 * null here and a 404 from slice 4's replyToContact.
 * Quiet hours do not apply: holding a Messenger reply could carry it past the
 * 24-hour window, and Messenger is not a text message.
 */
export async function metaReplyFor(input: { onboardingId: number; contactId: number; text: string; via?: 'sms' | null; now?: number }): Promise<MetaReplyResult | null> {
  if (input.via === 'sms') return null;
  const now = input.now ?? Date.now();
  const [lastMetaRes, lastOtherRes, contactRes] = await Promise.all([
    sql<{ channel: MetaChannel; page_id: string; person_id: string; sent_at: Date | string }>`
      SELECT channel, page_id, person_id, sent_at FROM meta_messages
      WHERE onboarding_id = ${input.onboardingId} AND contact_id = ${input.contactId} AND direction = 'in'
      ORDER BY sent_at DESC LIMIT 1;
    `,
    sql<{ at: Date | string | null }>`
      SELECT max(created_at) AS at FROM contact_events
      WHERE onboarding_id = ${input.onboardingId} AND contact_id = ${input.contactId} AND kind IN ('call', 'text_in', 'form', 'chat', 'booking');
    `,
    sql<{ phone: string | null }>`SELECT phone FROM contacts WHERE id = ${input.contactId} AND onboarding_id = ${input.onboardingId};`,
  ]);
  const last = lastMetaRes.rows[0];
  if (!last) return null;
  const hasPhone = Boolean(contactRes.rows[0]?.phone);

  });

  if (decision.route === 'blocked') return { ok: false, status: 409, error: decision.message, canText: decision.canText, channel: decision.channel };

  const name = PLATFORM[channel];
  const text = input.text.trim();
  if (!text) return { ok: false, status: 400, error: 'Type a message first.', canText: hasPhone, channel };
  if (text.length > META_TEXT_MAX) return { ok: false, status: 400, error: `Keep it under ${META_TEXT_MAX.toLocaleString('en-US')} characters.`, canText: hasPhone, channel };

    return { ok: false, status: 409, error: `This ${name} page needs to be reconnected before you can reply here. Axeon has been told.`, canText: hasPhone, channel };

  } catch (err) {

      await markNeedsReconnect(page.pageId, err.message);
      return { ok: false, status: 502, error: `${name} stopped accepting replies from this page. Axeon has been told and will reconnect it.`, canText: hasPhone, channel };

    if (err instanceof MetaApiError && err.outsideWindow) {
      return { ok: false, status: 409, error: `${name} only lets you reply within 24 hours of their last message.${hasPhone ? ' Text them instead?' : ''}`, canText: hasPhone, channel };
    }
    console.error('[meta:reply]', redactedErr(err));
    return { ok: false, status: 502, error: `${name} did not take the message. Try again in a minute.`, canText: hasPhone, channel };
  }

  const out = await sql<{ id: DbId }>`
    INSERT INTO meta_messages (onboarding_id, contact_id, channel, direction, page_id, person_id, mid, body, sent_at)
    VALUES (${input.onboardingId}, ${input.contactId}, ${channel}, 'out', ${page.pageId}, ${last.person_id}, ${messageId}, ${text}, now())
    ON CONFLICT (mid) DO NOTHING
    RETURNING id;
  `;
  await addContactEvent({
    onboardingId: input.onboardingId,
    contactId: input.contactId,
    kind: channel,
    refTable: 'meta_messages',
    refId: out.rows[0] ? Number(out.rows[0].id) : null,

    // A reply the client typed is contact: New moves to Contacted through slice 4's advanceStage
    // (forms mirror it, slice 3's new-lead and quote follow-ups stop), as a typed text does.
    systemStage: 'contacted',
  });
  return { ok: true, channel };
}
```

```ts
/** Inbound touches other than a DM that send the reply by text instead (the same list metaReplyFor's SQL uses). */
export const OTHER_INBOUND_KINDS: readonly string[] = ['call', 'text_in', 'form', 'chat', 'booking'];

/**
 * replyDecision's inputs, read from the timeline the inbox page already has
 * (slice 4's DashboardEvent with metaDirection). The reply box uses it only to
 * pick its wording; the server decides again in metaReplyFor.
 */
export function replyContextFrom(events: ReadonlyArray<{ kind: string; at: string; metaDirection: 'in' | 'out' | null }>): {
  lastMeta: { channel: MetaChannel; at: string } | null;
  lastOtherInboundAt: string | null;
} {
  let lastMeta: { channel: MetaChannel; at: string } | null = null;
  let lastOther: string | null = null;
  for (const e of events) {
    if ((e.kind === 'messenger' || e.kind === 'instagram') && e.metaDirection === 'in') {
      if (!lastMeta || time(e.at) >= time(lastMeta.at)) lastMeta = { channel: e.kind, at: e.at };
    } else if (OTHER_INBOUND_KINDS.includes(e.kind)) {
      if (!lastOther || time(e.at) >= time(lastOther)) lastOther = e.at;
    }
  }
  return { lastMeta, lastOtherInboundAt: lastOther };
}
```

```ts
// lib/socialShared.ts
// Client-safe rules for reels posting (AxeonGROWTH): what a valid post is, where
// its video may live, and what the hourly cron does next with each row. The
// admin Social card validates with the same functions the API uses.
import { captionProblem, SOCIAL_PLATFORMS, type DashboardReel, type SocialPlatform, type SocialPost, type SocialStatus } from '@/lib/metaShared';

/** Vercel Blob public URLs: https://<store>.public.blob.vercel-storage.com/<path>. Only our own uploads are posted. */
export const BLOB_HOST_SUFFIX = '.public.blob.vercel-storage.com';
/** Instagram reels: MP4 or MOV, up to 300 MB (the smaller of the IG and Facebook limits). */
export const REEL_MAX_BYTES = 300 * 1024 * 1024;
export const REEL_CONTENT_TYPES = ['video/mp4', 'video/quicktime'] as const;
export const SCHEDULE_MAX_DAYS = 60;
/** A post that fails this many times for a reason that might pass (network, 5xx) is marked failed. */
export const MAX_ATTEMPTS = 3;

export interface SocialInput {
  platforms: SocialPlatform[];
  videoUrl: string;
  caption: string;
  /** ISO time, or null to save as a draft. */
  scheduledAt: string | null;
}

/** The Blob path every upload for a client must use: social/<onboarding id>/<file>. Never the portal token. */
export function blobPathFor(onboardingId: number, filename: string): string {
  const clean = filename.toLowerCase().replace(/[^a-z0-9.]+/g, '-').replace(/^-+|-+$/g, '').slice(-60) || 'reel.mp4';
  return `social/${onboardingId}/${clean}`;
}

export function isBlobPathFor(onboardingId: number, pathname: string): boolean {
  return new RegExp(`^social/${onboardingId}/[a-z0-9.-]{1,80}$`).test(pathname);
}

export function isBlobVideoUrl(raw: string, onboardingId: number): boolean {
  try {
    const u = new URL(raw);
    return u.protocol === 'https:' && u.hostname.endsWith(BLOB_HOST_SUFFIX) && u.pathname.startsWith(`/social/${onboardingId}/`);
  } catch {
    return false;
  }
}

/** A schedule time the cron can honour: not more than 5 minutes in the past, not more than 60 days out. */
export function validateScheduleTime(raw: unknown, now: number = Date.now()): string {
  const t = typeof raw === 'string' ? Date.parse(raw) : NaN;
  if (!Number.isFinite(t)) throw new Error('Pick a date and time to post it.');
  if (t < now - 5 * 60_000) throw new Error('That time has already passed.');
  if (t > now + SCHEDULE_MAX_DAYS * 86_400_000) throw new Error(`Schedule it within the next ${SCHEDULE_MAX_DAYS} days.`);
  return new Date(t).toISOString();
}

export function validateSocialInput(raw: unknown, onboardingId: number, now: number = Date.now()): SocialInput {
  const body = raw && typeof raw === 'object' ? (raw as Record<string, unknown>) : {};
  const platforms = Array.isArray(body.platforms) ? [...new Set(body.platforms.filter((p): p is SocialPlatform => SOCIAL_PLATFORMS.includes(p as SocialPlatform)))] : [];
  if (!platforms.length) throw new Error('Choose Instagram, Facebook, or both.');
  const videoUrl = typeof body.videoUrl === 'string' ? body.videoUrl.trim() : '';
  if (!isBlobVideoUrl(videoUrl, onboardingId)) throw new Error('Upload the video first.');
  const caption = typeof body.caption === 'string' ? body.caption.replace(/\r\n/g, '\n').trim() : '';
  const problem = captionProblem(caption);
  if (problem) throw new Error(problem);
  const scheduledAt = body.scheduledAt == null || body.scheduledAt === '' ? null : validateScheduleTime(body.scheduledAt, now);
  return { platforms, videoUrl, caption, scheduledAt };
}

export type SocialStep = 'skip' | 'create_container' | 'check_container' | 'publish_facebook';

/** What the cron does with one row right now. Pure so the order of the flow is pinned by tests. */
export function nextSocialStep(post: { platform: SocialPlatform; status: SocialStatus; scheduledAt: string | null; containerId: string | null }, now: number): SocialStep {
  if (post.status !== 'scheduled' || !post.scheduledAt || Date.parse(post.scheduledAt) > now) return 'skip';
  if (post.platform === 'facebook') return 'publish_facebook';
  return post.containerId ? 'check_container' : 'create_container';
}

/** True when a failure should end the post: Meta refused it outright (4xx), or it has failed MAX_ATTEMPTS times. */
export function shouldGiveUp(attemptsSoFar: number, httpStatus: number): boolean {
  if (httpStatus >= 400 && httpStatus < 500) return true;
  return attemptsSoFar + 1 >= MAX_ATTEMPTS;
}

export function toDashboardReel(p: SocialPost): DashboardReel | null {
  if (p.status !== 'published' || !p.publishedAt) return null;
  return { platform: p.platform, caption: p.caption, publishedAt: p.publishedAt, permalink: p.permalink, reach: p.reach, plays: p.plays };
}
```

```ts
// writes a caption and picks a time; one social_posts row per platform. The
// hourly cron (app/api/cron/social) publishes due rows: Instagram through the
// container flow (create → wait for FINISHED → media_publish), Facebook through
// one /{page-id}/videos call. The same cron refreshes Instagram reach daily.
// Server-only.

import { ensureSchema, sql } from '@/lib/db';
import { errText, iso, type DbTime } from '@/lib/dbRows';
import type { Onboarding } from '@/lib/onboarding';

  id: number;
  onboarding_id: number;
  platform: SocialPlatform;
  page_id: string;
  video_url: string;
  caption: string;
  scheduled_at: DbTime | null;

  reach: number | null;

export async function listSocialPosts(onboardingId: number, limit = 50): Promise<SocialPost[]> {

/** One row per platform. Instagram needs a page with a linked Instagram professional account. */
export async function createSocialPosts(onboarding: Onboarding, input: SocialInput): Promise<SocialPost[]> {
  assertGrowth(onboarding);
  const pages = (await pagesFor(onboarding.id)).filter((p) => p.status === 'active');
  if (!pages.length) throw new Error('Connect the client\'s Facebook page first.');
  const page = pages[0];
  if (input.platforms.includes('instagram') && !page.igUserId) throw new Error('This Facebook page has no Instagram professional account linked. Post to Facebook only, or link Instagram in Meta Business Suite and reconnect.');
  const status: SocialStatus = input.scheduledAt ? 'scheduled' : 'draft';
  const out: SocialPost[] = [];

      VALUES (${onboarding.id}, ${platform}, ${page.pageId}, ${input.videoUrl}, ${input.caption}, ${input.scheduledAt}, ${status})

    out.push(toPost(res.rows[0]));
  }

/** Schedules a draft or retries a failed post at a new time. */
export async function scheduleSocialPost(onboardingId: number, id: number, rawTime: unknown): Promise<void> {

export interface CronDeps {
  sleep: (ms: number) => Promise<void>;
  now: () => Date;
}

const realDeps: CronDeps = { sleep: (ms) => new Promise((r) => setTimeout(r, ms)), now: () => new Date() };
const POSTS_PER_RUN = 5;
const POLL_TRIES = 6;
const POLL_MS = 5000;
const INSIGHTS_PER_RUN = 25;

async function markPublished(id: number, remoteId: string | null, permalink: string | null, note: string | null = null) {
  await sql`
    UPDATE social_posts SET status = 'published', remote_id = ${remoteId}, permalink = ${permalink}, error = ${note},
      published_at = now(), locked_until = NULL, updated_at = now()
    WHERE id = ${id};
  `;
}

async function markProblem(post: PostRow, err: unknown) {
  const status = err instanceof MetaApiError ? err.status : 0;
  const message = secretRedact(errText(err)).slice(0, 400);
  if (err instanceof MetaApiError && err.tokenInvalid) await markNeedsReconnect(post.page_id, message);
  const giveUp = (err instanceof MetaApiError && err.tokenInvalid) || shouldGiveUp(post.attempts, status);
  await sql`
    UPDATE social_posts SET attempts = attempts + 1, error = ${message}, status = ${giveUp ? 'failed' : 'scheduled'},
      container_id = ${giveUp ? null : post.container_id}, locked_until = NULL, updated_at = now()
    WHERE id = ${post.id};
  `;
  return giveUp;
}

async function release(id: number) {
  await sql`UPDATE social_posts SET locked_until = NULL, updated_at = now() WHERE id = ${id};`;
}

type Outcome = 'published' | 'failed' | 'waiting';

async function runOne(post: PostRow, deps: CronDeps): Promise<Outcome> {
  const step = nextSocialStep({ platform: post.platform, status: post.status, scheduledAt: isoOrNull(post.scheduled_at), containerId: post.container_id }, deps.now().getTime());
  if (step === 'skip') {
    await release(post.id);
    return 'waiting';
  }
  const page = await pageForId(post.page_id);
  if (!page || page.onboardingId !== post.onboarding_id) {
    await sql`UPDATE social_posts SET status = 'failed', error = 'The Facebook page is no longer connected.', locked_until = NULL, updated_at = now() WHERE id = ${post.id};`;
    return 'failed';
  }
  try {
    if (step === 'publish_facebook') {
      const videoId = await publishPageVideo({ pageId: page.pageId, pageToken: page.pageToken, videoUrl: post.video_url, description: post.caption });
      await markPublished(post.id, videoId, `https://www.facebook.com/${encodeURIComponent(page.pageId)}/videos/${encodeURIComponent(videoId)}`);
      return 'published';
    }
    if (!page.igUserId) {
      await sql`UPDATE social_posts SET status = 'failed', error = 'No Instagram account is linked to this page anymore.', locked_until = NULL, updated_at = now() WHERE id = ${post.id};`;
      return 'failed';
    }
    let containerId = post.container_id;
    if (!containerId) {
      containerId = await createReelContainer({ igUserId: page.igUserId, pageToken: page.pageToken, videoUrl: post.video_url, caption: post.caption });
      // Saved before polling, so a timeout here never creates a second container next hour.
      await sql`UPDATE social_posts SET container_id = ${containerId}, updated_at = now() WHERE id = ${post.id};`;
    }
    for (let i = 0; i < POLL_TRIES; i++) {
      const { code, detail } = await containerStatus(containerId, page.pageToken);
      if (code === 'FINISHED') {
        const mediaId = await publishContainer({ igUserId: page.igUserId, pageToken: page.pageToken, containerId });
        await markPublished(post.id, mediaId, await mediaPermalink(mediaId, page.pageToken));
        return 'published';
      }
      if (code === 'PUBLISHED') {
        // Published on an earlier run whose database write was lost; Instagram does not return the media id again.
        await markPublished(post.id, null, null, 'Posted. Instagram did not send back the post link.');
        return 'published';
      }
      if (code === 'ERROR' || code === 'EXPIRED') {
        const why = code === 'EXPIRED' ? 'Instagram did not finish processing the video within 24 hours.' : `Instagram could not process the video${detail ? `: ${detail}` : '.'}`;
        await sql`UPDATE social_posts SET status = 'failed', error = ${why.slice(0, 400)}, container_id = NULL, locked_until = NULL, updated_at = now() WHERE id = ${post.id};`;
        return 'failed';
      }
      if (i < POLL_TRIES - 1) await deps.sleep(POLL_MS);
    }
    await release(post.id);
    return 'waiting';
  } catch (err) {
    return (await markProblem(post, err)) ? 'failed' : 'waiting';
  }
}

async function refreshInsights(deps: CronDeps): Promise<number> {
  const due = await sql<PostRow>`
    SELECT * FROM social_posts
    WHERE status = 'published' AND platform = 'instagram' AND remote_id IS NOT NULL
      AND published_at > now() - interval '90 days'
      AND (insights_at IS NULL OR insights_at < now() - interval '20 hours')
    ORDER BY insights_at NULLS FIRST LIMIT ${INSIGHTS_PER_RUN};
  `;
  let updated = 0;
  for (const post of due.rows) {
    try {
      const page = await pageForId(post.page_id);
      if (!page) continue;
      const { reach, plays } = await mediaInsights(post.remote_id!, page.pageToken);
      await sql`UPDATE social_posts SET reach = COALESCE(${reach}, reach), plays = COALESCE(${plays}, plays), insights_at = ${deps.now().toISOString()}, updated_at = now() WHERE id = ${post.id};`;
      updated += 1;
    } catch (err) {
      console.error('[social] insights', post.id, secretRedact(errText(err)));
      // Try again tomorrow rather than every hour.
      await sql`UPDATE social_posts SET insights_at = ${deps.now().toISOString()} WHERE id = ${post.id};`;
    }
  }
  return updated;
}

/** The hourly cron. Claims up to five due posts with a 10-minute lease so an overlapping run cannot double-post. */
export async function runSocialCron(deps: CronDeps = realDeps): Promise<{ published: number; failed: number; waiting: number; insights: number }> {
  await ensureSchema();
  const claimed = await sql<PostRow>`
    UPDATE social_posts SET locked_until = now() + interval '10 minutes'
    WHERE id IN (
      SELECT p.id FROM social_posts p JOIN onboardings o ON o.id = p.onboarding_id
      WHERE p.status = 'scheduled' AND p.scheduled_at <= now() AND o.tier = 'axeongrowth' AND o.status <> 'closed'
        AND (p.locked_until IS NULL OR p.locked_until < now())
      ORDER BY p.scheduled_at LIMIT ${POSTS_PER_RUN}
      FOR UPDATE OF p SKIP LOCKED
    )
    AND (locked_until IS NULL OR locked_until < now())
    RETURNING *;
  `;
  const tally = { published: 0, failed: 0, waiting: 0, insights: 0 };
  for (const post of claimed.rows) tally[await runOne(post, deps)] += 1;
  tally.insights = await refreshInsights(deps);
  return tally;
}
```

```tsx
  const [posts, setPosts] = useState<SocialPost[]>(initial);
  const [videoUrl, setVideoUrl] = useState('');
  const [fileName, setFileName] = useState('');
  const [caption, setCaption] = useState('');
  const [platforms, setPlatforms] = useState<SocialPlatform[]>(['instagram', 'facebook']);
  const [at, setAt] = useState('');
  const [busy, setBusy] = useState<string | null>(null);
  const [error, setError] = useState<string | null>(null);

  if (tier !== 'axeongrowth') return null;
  const page = pages.find((p) => p.status === 'active') ?? null;
  const problem = captionProblem(caption);
  const api = `/api/admin/onboarding/${token}/social`;

  async function call(method: 'POST' | 'PATCH' | 'DELETE', body: Record<string, unknown>) {
    const res = await fetch(api, { method, headers: { 'content-type': 'application/json' }, body: JSON.stringify(body) });
    const json = (await res.json().catch(() => null)) as { posts?: SocialPost[]; error?: string } | null;
    if (!res.ok || !json?.posts) throw new Error(json?.error || `Request failed (${res.status})`);
    setPosts(json.posts);
  }

  async function run(label: string, fn: () => Promise<void>) {
    setBusy(label);
    setError(null);
    try {
      await fn();
    } catch (err) {
      setError(err instanceof Error ? err.message : 'Request failed');
    } finally {
      setBusy(null);
    }
  }

  function pickFile(file: File | undefined) {
    if (!file) return;
    if (file.size > REEL_MAX_BYTES) {
      setError('That video is over 300 MB. Export a shorter or smaller version.');
      return;

    void run('upload', async () => {
      const blob = await upload(blobPathFor(onboardingId, file.name), file, { access: 'public', handleUploadUrl: `${api}/upload`, multipart: true, contentType: file.type || 'video/mp4' });
      setVideoUrl(blob.url);
      setFileName(file.name);
    });
  }

    void run('save', async () => {
      await call('POST', { platforms, videoUrl, caption, scheduledAt: schedule && at ? new Date(at).toISOString() : null });
      setVideoUrl('');
      setFileName('');
      setCaption('');
      setAt('');
```

```ts
// app/api/meta/deauthorize/route.ts
// Meta's "Deauthorize callback URL": POSTed (form field signed_request) when a
// person removes the Axeon app from their Facebook settings. We forget every
// page they connected; the inbox keeps the messages already received.
import { NextResponse } from 'next/server';
import { metaUnavailable, parseSignedRequest } from '@/lib/meta';
import { removePagesForUser } from '@/lib/metaPages';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

export async function POST(req: Request) {
  const unavailable = metaUnavailable();
  if (unavailable) return unavailable;
  const form = await req.formData().catch(() => null);
  const signed = form?.get('signed_request');
  const parsed = parseSignedRequest(typeof signed === 'string' ? signed : null);
  if (!parsed) return NextResponse.json({ error: 'Bad signed_request' }, { status: 400 });
  const removed = await removePagesForUser(parsed.userId);
  return NextResponse.json({ ok: true, removed });
}
```

```ts
// app/api/meta/data-deletion/route.ts
// Meta's "Data Deletion Request callback URL". Meta POSTs signed_request when a
// person asks Facebook to delete what Axeon holds about them. We delete their
// connected pages and tokens at once and answer with Meta's required JSON:
// { url, confirmation_code }, where url shows the status to the person.
import { NextResponse } from 'next/server';
import { metaUnavailable, parseSignedRequest } from '@/lib/meta';
import { recordDeletion, removePagesForUser } from '@/lib/metaPages';
import { SITE_ORIGIN } from '@/lib/hostRouting';

export const runtime = 'nodejs';
export const dynamic = 'force-dynamic';

export async function POST(req: Request) {
  const unavailable = metaUnavailable();
  if (unavailable) return unavailable;
  const form = await req.formData().catch(() => null);
  const signed = form?.get('signed_request');
  const parsed = parseSignedRequest(typeof signed === 'string' ? signed : null);
  if (!parsed) return NextResponse.json({ error: 'Bad signed_request' }, { status: 400 });
  const code = await recordDeletion(await removePagesForUser(parsed.userId));
  return NextResponse.json({ url: `${SITE_ORIGIN}/meta/deletion?code=${code}`, confirmation_code: code });
}
```
